# inkivi — официальный сайт

Новый интерактивный сайт артиста **inkivi**, написанный на чистых HTML, CSS и JavaScript. Сайт рассчитан на публикацию через GitHub Pages из ветки `gh-pages`.

## Структура

- `index.html` — семантическая разметка стартового экрана, главного пространства и полноэкранных разделов.
- `css/` — базовые стили, стартовый экран, сцена, панели и адаптивность.
- `js/config.js` — все изменяемые данные и ссылки.
- `js/` — таймер, переходы, панели, визуалы, релизы и подключение игры.
- `assets/` — фоновые композиции, объекты сцены, обложки, превью и UI.
- `game/` — отдельная лёгкая браузерная игра, которая загружается только после нажатия.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.

## Локальный запуск

ES-модули нельзя корректно проверить двойным кликом по `index.html`. Запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Где менять контент

Все редактируемые данные находятся в `js/config.js`. Поле `timeZone` управляет часовым поясом отображаемых дат.

### Ближайший релиз и таймер

Измените объект `upcomingRelease`:

```js
upcomingRelease: {
  enabled: true,
  title: 'название',
  date: '2026-09-18T00:00:00+03:00',
  presaveUrl: 'https://...',
  cover: './assets/releases/upcoming.webp'
}
```

- `enabled: true` включает состояние с таймером.
- Если дата уже наступила или `enabled: false`, сайт автоматически показывает последний релиз.
- Всегда указывайте часовой пояс в дате.

### Последний релиз

Обновите `latestRelease`: название, дату, путь к обложке и `bandlink`.

### Добавление релиза

Добавьте объект в массив `releases`. Ссылки на отсутствующие площадки можно удалить. Поддерживаются любые ключи; известные площадки получают русские подписи автоматически.

### Добавление визуала

Добавьте объект в массив `visuals`:

```js
{
  title: 'название',
  thumbnail: './assets/visuals/visual-05.webp',
  url: 'https://www.tiktok.com/...',
  date: '2026-08-01'
}
```

На странице загружаются только изображения-превью. TikTok iframe не создаются.

### Социальные сети

Обновите объект `socials`. Временное значение `#` делает ссылку неактивной без ошибки навигации.

## Подключение игры

Настройки находятся в `siteConfig.game`:

```js
game: {
  enabled: true,
  title: 'inkivi.exe',
  description: 'описание',
  url: './game/index.html',
  preview: './assets/game/preview.webp'
}
```

`url` может вести на локальную HTML-страницу, Unity WebGL loader или внешний URL. Игра помещается в iframe только после нажатия «запустить игру».

## Замена временных изображений

Текущие SVG — законченные лёгкие заглушки. Их можно заменить на WebP/AVIF или прозрачные PNG, сохранив пути из конфигурации и имена объектных файлов:

- `assets/backgrounds/start.svg` — фон релизного экрана;
- `assets/backgrounds/room.svg` — десктопная сцена;
- `assets/objects/door.svg` — дверь;
- `assets/objects/tv.svg` — CRT-телевизор;
- `assets/objects/cd-stack.svg` — музыкальный объект;
- `assets/objects/computer.svg` — компьютер;
- `assets/objects/cat.svg` — кот-маскот;
- `assets/releases/` — обложки;
- `assets/visuals/` — вертикальные превью;
- `assets/game/preview.svg` — превью игры.

Для растровых фонов желательно использовать AVIF/WebP. PNG оставляйте только для объектов с прозрачностью.

## Адаптивность и доступность

- Десктоп использует сцену 16:9 с ограниченной максимальной шириной.
- На ширинах до 900 px включается отдельная вертикальная мобильная композиция.
- Учитываются `100svh`, `100dvh` и safe-area iPhone.
- Разделы закрываются по Escape, кнопке закрытия и кнопке возврата.
- Есть управление клавиатурой, мышью, касанием и свайпом в визуалах.
- При `prefers-reduced-motion: reduce` сложные движения заменяются быстрыми fade-переходами.

## Публикация GitHub Pages

Рабочая ветка сайта — `gh-pages`, файл `index.html` находится в корне. После коммита GitHub Pages должен публиковать адрес:

`https://inkivi.github.io/inkivi/`

В настройках репозитория GitHub Pages выберите **Deploy from a branch**, ветку `gh-pages`, папку `/ (root)`. После публикации проверьте URL с query-параметром и без него.
